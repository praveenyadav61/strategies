SLIDE 3 — THE LIFECYCLE
==================================================

Title:
Every valid base moves through the same lifecycle

Stage 1 — Discover:
A completed weekly structure passes depth, duration, trend and prior-advance checks.

Stage 2 — Recover:
Price progresses from the base low toward the left-side high.

Stage 3 — Prepare:
The structure reaches the review zone and one actionable pivot is identified.

Stage 4 — Breakout:
Price crosses a volatility-aware trigger above the pivot.

Stage 5 — Resolve:
The system records success, warning or failure without erasing earlier history.

Important distinction:
- Recovery can move forward or backward.
- Breakout, success and failure are historical events and remain recorded.

Use one horizontal lifecycle arrow with five stages. Avoid separate cards if the journey can be shown as one connected flow.

SLIDE 5 — HOW THE SYSTEM DECIDES WHAT TO TRACK
==================================================

Title:
A structure is validated before its recovery is measured

Discovery:
- Use only completed weekly candles.
- Evaluate long, medium and shorter historical windows.
- Find a valid left-side high followed by a later base low.

Validation:
- Base depth must be between 15% and 60%.
- Base duration must be at least 12 weeks.
- Prior advance, long-term trend and abnormal-week checks must pass.

Consolidation:
- Equivalent windows are grouped.
- The largest representative window is retained.
- Genuinely different nested structures remain separate.

Tracking:
- The structure enters the active lifecycle when recovery reaches 40%.

Key message:
The system first proves that the structure is meaningful. Only then does it begin lifecycle tracking.

==================================================
SLIDE 6 — HOW THE SYSTEM DECIDES WHAT IS ACTIONABLE
==================================================

Title:
Recovery, pivot and outcome are separate decisions

Recovery state:
- Below 40%: recorded but outside the main review flow
- 40% to below 85%: Recovery Building
- 85% or higher: Breakout Consideration

Actionable pivot:
- Begin with the original left-side high.
- Replace it only when a valid handle candidate is confirmed.
- Maintain only one active pivot.
- Freeze the pivot when breakout occurs.

Outcome:
- Breakout requires a close above a volatility-aware trigger.
- Success requires meaningful follow-through beyond the pivot and old supply.
- Failure uses separate warning and hard-failure levels.

Key message:
The system does not treat recovery, entry, success and failure as the same threshold. Each answers a different question.

Visual:
Use three clearly separated layers:
Recovery → Action level → Outcome

APPENDIX A — RECOVERY FORMULA

Recovery percentage =
(Current close − Base low) ÷ (Left-side high − Base low)

Interpretation:
- Below 40%: outside main review flow
- 40% to below 85%: Recovery Building
- 85% or higher: Breakout Consideration

APPENDIX B — BREAKOUT AND FAILURE LEVELS

Breakout trigger:
Pivot + maximum of:
- 0.5% of pivot
- 0.20 × ATR14

Hard-failure level:
0.90 × pivot − buffer

Buffer:
Maximum of:
- 1% of pivot
- 0.25 × ATR
